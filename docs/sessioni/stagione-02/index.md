# Stagione 2 — Gli Eroi della Soglia

**Livello di difficoltà: EQUILIBRATA**

Dieci anni dopo la Forgia. Un nuovo gruppo, una città diversa, e un mondo che nel frattempo si è mosso — anche nei posti dove nessuno stava guardando.
