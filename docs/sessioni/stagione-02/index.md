# Stagione 2 — Gli Eroi della Soglia

**Flamerule 25 – Eleasias 11, 1499 DR**

Dieci anni dopo la Forgia. Un nuovo gruppo, una città diversa, e un mondo che nel frattempo si è mosso — anche nei posti dove nessuno stava guardando.

!!! info "Il party"
    - **Willadrias Gargadol** — elfo alto, warlock del Grande Antico
    - **Vaelith Drakos** — tiefling, stregone Magia Draconica
    - **Sangtiennoi** — aasimar, monaco della Mano Aperta

    Con loro: **Klynt**, goliath guerriero psionico
